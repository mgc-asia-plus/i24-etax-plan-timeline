🔑 Key facts (sync จากโค้ดจริง)

  • ใบลดหนี้ (CN) = มี APPLY_TO_INVOICE_NO AND INVOICE_AMOUNT < 0 AND ใบต้นฉบับมีใบกำกับภาษี → 81
  • Doc type: amount ≥ 0 + มี tit → T03 · amount ≥ 0 ไม่มี tit → บล็อก · amount < 0 ไม่เข้าเกณฑ์ CN → บล็อก+guard
  • F34 payment จาก CASH_TRANSACTIONS (via tit.RECEIPT) + CREDIT_CARDS · mask 4 หลักท้าย · คั่น " | " Title Case (10 ก.ย.)
  • F68 WHT = Σ(DEBIT−CREDIT) จาก ACCOUNT_TRANS (ACCOUNT_NAME='WHT')
  • F70 = Agreement No.: เสมอ · ใบลดหนี้ต่อ Reason: {credit_note_reason} (REMARKS.RMK_REMARK) · ต่อท้าย F34 · ไม่ใช้ agreement_remark
  • ต้นทาง Phase 1 = carpro_web: invoice list + PDF PrintTaxInvoicThai + IREM/agreement/driver + Handle Payment (หา H07 ของ 81) · env CARPRO_WEB_COOKIE
  • Job = /e-tax/job-scheduler 12:00 / 18:00 / 23:00 · batch = force_resubmit ก่อน แล้วใบวันนี้จาก carpro-live
  • Raw/staging (i24-data-platform) → Phase 2 · intake staging ถูกปิดในโค้ด
